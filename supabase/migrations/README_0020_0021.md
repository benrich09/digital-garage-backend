# Migrations 0020 & 0021

## Apply in Supabase SQL Editor (order matters)

1. Run `0020_job_lifecycle_reviews_reports.sql`
2. Run `0021_settlement_receipts_and_payback.sql`

## What they enable

### 0020 — Whole job flow
- `service_requests.request_kind` (`mechanic_request` | `garage_booking`)
- `preferred_garage_id` for targeted garage bookings
- Booking lifecycle: `bill_amount`, `customer_satisfied`, `payment_confirmed`, timers
- Mutual reviews (`car_owner_id` on `reviews`)
- `incident_reports` + RLS
- Realtime on requests / bookings / reports

### 0021 — Commission payback
- `provider_settlements.receipt_url`
- Transaction indexes
- Storage bucket `settlement-receipts`

## Flow (after migrations)

**Mechanic request:** car owner creates `request_kind=mechanic_request` → mechanics inbox → accept → track → arrive → start → finish → satisfied → bill → pay → provider confirms → mutual rate.

**Garage booking:** car owner creates `request_kind=garage_booking` + `preferred_garage_id` → that garage inbox → accept → customer arrives → start → finish → satisfied → bill → pay → confirm → rate.
